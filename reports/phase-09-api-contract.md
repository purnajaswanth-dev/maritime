## 1. Zero Mock Data Contract & Data Ownership Matrix

### A. Non-Negotiable Acceptance Mandate
All operational endpoints defined in this contract must serve **genuine integrated data** generated by the Python virtual maritime simulation and inference engine.
- Under **no circumstances** may Spring Boot return canned success payloads, hardcoded vessel coordinates, or fabricated ETA values to mask an outage.
- If the Python simulation engine is offline or unreachable, Spring Boot must return a structured **HTTP 503 Service Unavailable** response compliant with RFC 7807 (`ProblemDetail`).
- Operational frontend components must consume these contracts and display explicit error/reconnecting states rather than falling back to hardcoded fixtures.

### B. Ownership Matrix

| Domain Entity | Authoritative Owner | Read/Cache Gateway | Presentation Layer | Mutation Authority |
|---|---|---|---|---|
| **Virtual Telemetry (Lat, Lon, SOG, COG)** | Python Virtual Maritime Engine | Spring Boot (`FleetCacheService`) | Frontend (`FleetMap`) | Python Simulation Engine only |
| **ETA Predictions & State Machine** | Python `ETAStreamProcessor` | Spring Boot (Proxy/Validator) | Frontend (`VesselDetailPanel`) | Python Model (`VectorizedRidgeETAModel`) |
| **Active Simulation Clock & Scenarios** | Python `VirtualFleetRunner` | Spring Boot (`SimulationService`) | Frontend Admin (`AdminSimulationControlsPage`) | Admin UI &rarr; Spring Boot &rarr; Python |
| **Static Terminals & Schedules** | Spring Boot / Shared Configuration | In-memory cache | Frontend (`SearchResultsPage`, `PortsPage`) | Static configuration |
| **Live SSE Connection Management** | Spring Boot Gateway | Spring Boot `SseEmitterRegistry` | Frontend `useEventSource` hook | Spring Boot Gateway |

All public frontend requests communicate with Spring Boot over `http://localhost:8080`.

## 3. Real-Time Server-Sent Events (SSE) Stream

### `GET /api/v1/stream/vessels`
- **Protocol:** Server-Sent Events (`text/event-stream;charset=UTF-8`)
- **Connection Lifecycle:**
  1. **Connection Established:** Client opens EventSource with `withCredentials: false`.
  2. **Initial Event (`event: snapshot`):** Dispatched immediately upon connect. Contains all 4 active vessels.
  3. **Continuous Streaming (`event: telemetry_update`):** Emitted every 1.0 to 5.0 seconds as synthetic AIS pings are generated by Python.
  4. **State Transition (`event: eta_transition`):** Emitted when a vessel changes state (e.g. `IN_TRANSIT` &rarr; `APPROACHING` &rarr; `ARRIVED` or `STALE`).
  5. **Heartbeat (`event: ping`):** Emitted every 15 seconds. If the client misses 2 consecutive pings, it marks the connection degraded.

### SSE Reconnection & Zero-Mock Policy
If the SSE connection drops:
- The frontend **must not** synthesize fake vessel movements.
- The browser EventSource automatically attempts HTTP reconnects with exponential backoff.
- The UI shows `Connection Reconnecting...` with last valid timestamp.

## 4. Simulation Administration & Scenarios

### 1. `POST /api/v1/simulation/controls`
- **Powers:** `AdminSimulationControlsPage`
- **Request Body:**
```json
{
  "action": "pause", // "start" | "stop" | "pause" | "resume" | "reset" | "speed"
  "speed_multiplier": 5.0
}
```
- **Response `200 OK`:** `{"status": "SUCCESS", "current_action": "pause", "is_paused": true}`

### 2. `POST /api/v1/simulation/scenarios/{scenarioId}`
- **Powers:** Scenario activation in Admin panel
- **Parameters:** `scenarioId` (`scenario-1` to `scenario-4`)
- **Response `200 OK`:**
```json
{
  "status": "APPLIED",
  "scenario_id": "scenario-2",
  "title": "Scenario 2: Severe Fromveur Current & Delay",
  "vessel_affected": "V-FROMVEUR-SIM",
  "induced_state": "UNCERTAIN"
}
```

## 5. Internal Service-to-Service Contract (Spring Boot &harr; Python)

Spring Boot communicates with the Python Maritime Daemon over internal loopback `http://127.0.0.1:8000/internal/v1/*`.

| Method | Internal Path | Purpose | Error Behavior |
|---|---|---|---|
| `GET` | `/internal/v1/status` | Engine heartbeat and simulation clock check | Returns 503 if daemon is stopping |
| `GET` | `/internal/v1/fleet/snapshot` | Fetch complete current state of all 4 vessels | Returns cached state if within 2.0s; else 503 |
| `GET` | `/internal/v1/fleet/events` | Long-polling event stream for Spring Boot ingestion | Reconnects on connection timeout |
| `POST` | `/internal/v1/control` | Relay simulation control actions from admin portal | Propagates error response to admin client |
| `POST` | `/internal/v1/scenarios/{id}` | Relay scenario fault injection | Returns 404 if scenario ID invalid |
